# GLOBAL 120 — Corporate Intelligence Dashboard

An interactive corporate intelligence dashboard presented by **Pietenium**.

## 🌐 Live Website

**https://pietenium.github.io/**

The project is designed to run directly as a GitHub Pages website using `index.html` as the root homepage.

## ✨ Features

- Interactive **3D global exchange/capital distribution globe**
- Directory of **120 public companies**
- Company search and filtering
- Country, sector, industry, exchange, market-cap and profitability filters
- Multiple sorting options
- 3D card view and table view
- Detailed company information modal
- Interactive financial analytics and charts
- Compare up to **4 companies**
- Predefined comparison presets
- Research methodology and data-confidence classification
- Responsive desktop and mobile layout
- Dark / light theme support

The interface includes sections for Overview, Companies, Financials, Compare, Insights, and Methodology.

## 🛠️ Technologies

This project is built as a browser-based HTML application with:

- HTML5
- CSS3
- JavaScript
- [Three.js](https://threejs.org/) — interactive 3D visualization
- [Chart.js](https://www.chartjs.org/) — financial charts
- Google Fonts

Three.js and Chart.js are loaded through external CDNs.

## 📊 Data & Methodology

The dashboard includes embedded corporate data, financial metrics, derived ratios, source references, and confidence classifications. It explicitly documents its research methodology and identifies estimated information where applicable.
